# StaticGram Desktop

Desktop client of the StaticGram network, based on
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop)
(GPL-3.0 with the OpenSSL exception).

Design based on mokaGram by @ecronx (https://t.me/ecronx). https://github.com/mokagram/mokagram

Only the visual design of mokaGram is used (styles, palette, settings cards,
round avatars and bubbles, floating input and search, section icons,
animations). mokaGram features (plugins, ghost/streamer modes, saved deleted
messages, security tools, music extras, quick commands and others) are removed.
See MOKAGRAM_NOTICE.md for the mokaGram attribution terms.
